北村 瞳 公式サイト — 公開準備パッケージ

内容
- index.html : ホームページ本体
- assets/portrait-main.jpg : メイン写真（トップ・プロフィール）
- assets/portrait-01.jpg〜portrait-04.jpg : ギャラリー写真
- README.txt : 公開手順

公開前の最終確認（必須）
1. index.html の YOUR_EMAIL@example.com を公開用メールアドレスに変更。
2. INSTAGRAM_URL / X_URL / YOUTUBE_URL を本人の実際のSNS URLに変更。使わないSNSは該当リンクを削除。
3. ニュース欄の仮日付・仮文章を実際の情報に置き換えるか、ニュース欄を削除。
4. 出演歴・役名・年・所属表記を本人の記録に照合。未確認の経歴をそのまま公開しない。
5. プロフィール文や特技・趣味が現状と一致するか確認。
6. 写真の掲載許可・著作権・事務所のルールを確認。
7. スマートフォンで全セクションとリンクを確認。

無料公開：GitHub Pages（アカウント操作は本人が行います）
1. GitHubにログインし、New repository から Public リポジトリを作成。例：hitomi-kit​​amura-portfolio（名前は任意）。
2. このZIPを解凍し、index.html、README.txt、assets フォルダをリポジトリの最上位にアップロード。
3. リポジトリの Settings → Pages を開く。
4. Build and deployment の Source を Deploy from a branch にし、Branch は main、フォルダは / (root) を選択して Save。
5. 公開URLが表示されたら開き、画像・メニュー・メールリンクを確認。

重要
- このパッケージの作成だけでは、インターネット公開は完了していません。GitHubへのログインと公開設定が必要です。
- お問い合わせボタンはメールアプリを開く mailto 方式です。フォーム送信機能はありません。
- 無料ホスティングの仕様や画面は変更されることがあります。
